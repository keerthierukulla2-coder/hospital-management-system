# Hospital Management System

A web-based hospital management system built using Flask and SQLite to manage patients, doctors, pharmacy, and administrative records.

## Features
- Add and delete patient records
- Add and delete doctor records
- Add and delete pharmacy records
- Add and delete admin records

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
